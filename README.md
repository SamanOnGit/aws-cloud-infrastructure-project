# AWS Cloud Infrastructure Project

A hands-on AWS project demonstrating the setup and configuration of essential cloud infrastructure services.

## Project Overview

This project explores how different AWS services work together to build a basic cloud infrastructure.

## AWS Services Covered

- **Amazon VPC** – Custom Virtual Private Cloud
- **Subnets** – Public and private subnets across multiple Availability Zones
- **Amazon EC2** – Virtual server instances
- **Bastion Host** – Access to instances in private subnets
- **Application Load Balancer (ALB)** – Distributing incoming traffic
- **Auto Scaling Group (ASG)** – Managing EC2 instance capacity
- **Amazon ECR** – Container image registry

## Architecture & Implementation

The project includes hands-on practice with:

- Creating and configuring a custom VPC
- Setting up public and private subnets
- Working with EC2 instances and security groups
- Configuring a Bastion Host
- Setting up an Application Load Balancer
- Exploring Auto Scaling configurations
- Working with Amazon ECR
